## 📌 프로젝트 소개

**깊이 우선 탐색(DFS)** 알고리즘을 단순히 코드로만 이해하는 것에서 나아가, 탐색 과정을 눈으로 직접 확인할 수 있도록 시각화한 프로젝트입니다.

캐릭터가 미로를 탐색하고, 막다른 길에서 **백트래킹**하는 과정을 애니메이션으로 표현합니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎲 **랜덤 미로 생성** | 실행할 때마다 재귀 백트래킹 알고리즘으로 새로운 미로 생성 |
| 🖼️ **픽셀 아트 미로** | 하드코딩된 20×17 크기의 픽셀 아트 스타일 미로 |
| 📐 **간단 미로** | DFS 동작 원리 학습용 소형 미로 |
| 🔴 **막다른 길 강조** | 백트래킹 시 붉은 플래시 애니메이션으로 막다른 길 시각화 |
| 📊 **실시간 통계** | 탐색 스텝 수 / 백트래킹 횟수 / 막다른 길 수 실시간 표시 |
| ⚡ **속도 조절** | 느림 / 보통 / 빠름 / 최고속 4단계 슬라이더 |

## 🧠 알고리즘 설명

### 깊이 우선 탐색 (DFS)

```
시작점에서 출발
 └─ 이동 가능한 방향 탐색 (우 → 하 → 좌 → 상)
     ├─ 이동 가능하면 → 재귀 호출 (더 깊이)
     └─ 막힌 곳이면 → 백트래킹 (이전 위치로 복귀)
         └─ 도착점 발견 시 → 탐색 종료 & 경로 하이라이트
```

### 랜덤 미로 생성 (재귀적 백트래킹)

1. 전체를 벽으로 초기화
2. 시작점 `(1, 1)`에서 랜덤 방향으로 2칸씩 이동하며 벽을 제거
3. 추가로 일부 벽을 제거해 막다른 곁길(Dead End) 생성

## 🚀 실행 방법

### 1. 의존성 설치

```bash
pip install flet
```

### 2. 실행

```bash
python main.py
```

### 3. 사용법

1. 상단 버튼으로 미로 모드 선택 (`랜덤` / `픽셀 아트` / `간단`)
2. `새 미로` 버튼으로 랜덤 미로 재생성
3. 속도 슬라이더로 탐색 속도 조절
4. `탐색 시작 (DFS)` 버튼 클릭

## 📚 사용 기술

- **Python 3.10+**
- **Flet** — Python 기반 크로스플랫폼 UI 프레임워크
- **asyncio** — 비동기 애니메이션 처리
- **재귀 DFS** — 미로 탐색 및 미로 생성 알고리즘
