## 📖 프로젝트 소개

Dart를 활용하여 **선형 덱(Linear Deque)** 과 **원형 덱(Circular Deque)** 을 직접 구현한 자료구조 프로젝트입니다.

양쪽 끝에서 데이터의 삽입과 삭제가 가능한 Deque(Double Ended Queue)의 동작 원리를 이해하고, 선형 구조와 원형 구조의 차이점을 비교하기 위해 구현하였습니다.

## ✨ 주요 기능

* 선형 덱(Linear Deque) 구현
* 원형 덱(Circular Deque) 구현
* 양방향 삽입 및 삭제 기능 제공
* 덱의 공백(Empty) 및 포화(Full) 상태 확인
* 콘솔 기반 동작 검증 테스트

---

## 🧠 구현 내용

### Linear Deque

배열의 중앙을 시작 위치로 설정하여 앞쪽과 뒤쪽 모두 데이터를 삽입할 수 있도록 구현하였습니다.

* 앞쪽 삽입 (addFirst)
* 뒤쪽 삽입 (addLast)
* 앞쪽 삭제 (removeFirst)
* 뒤쪽 삭제 (removeLast)
* 공간이 한쪽 방향으로만 확장되는 선형 구조

### Circular Deque

원형 인덱스 연산(Modulo)을 활용하여 배열의 끝과 시작을 연결한 구조로 구현하였습니다.

* 양방향 삽입 및 삭제 지원
* 사용 후 공간 재활용 가능
* 배열 끝에 도달해도 처음 위치부터 다시 사용 가능
* 메모리 활용 효율 향상

---

## 🔍 선형 덱과 원형 덱 비교

| 구분     | Linear Deque | Circular Deque |
| ------ | ------------ | -------------- |
| 구조     | 선형 배열        | 원형 배열          |
| 공간 재사용 | 불가능          | 가능             |
| 메모리 효율 | 상대적으로 낮음     | 상대적으로 높음       |
| 구현 난이도 | 쉬움           | 보통             |
| 인덱스 처리 | 일반 인덱스       | 모듈러 연산 활용      |

---

## 🎯 프로젝트 목표

Deque 자료구조의 동작 원리를 이해하고, 선형 구조와 원형 구조의 차이점을 직접 구현을 통해 학습하는 것을 목표로 하였습니다.

특히 원형 덱을 구현하며 모듈러 연산을 이용한 인덱스 순환 처리와 공간 재활용 방식을 학습할 수 있었습니다.
