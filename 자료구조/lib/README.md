## 📖 프로젝트 소개

BFS(Breadth First Search) 알고리즘을 활용하여 미로에서 시작 지점부터 목표 지점까지의 최단 경로를 탐색하는 시뮬레이터입니다.

탐색 과정을 실시간으로 시각화하여 BFS가 어떤 방식으로 노드를 탐색하고 최단 경로를 찾는지 직관적으로 확인할 수 있도록 구현하였습니다.

## ✨ 주요 기능

* BFS 알고리즘 기반 최단 경로 탐색
* 탐색 과정 실시간 시각화
* 방문 노드 표시
* 최단 경로 하이라이트
* 시작 지점(Start) 및 목표 지점(Goal) 구분
* Queue를 활용한 탐색 로직 구현

---

## 🧠 구현 내용

BFS의 핵심 자료구조인 Queue를 활용하여 탐색 순서를 관리하였으며, 방문한 노드는 Set으로 관리하여 중복 탐색을 방지하였습니다.

또한 각 노드의 부모 정보를 저장하여 목표 지점 도달 후 최단 경로를 역추적할 수 있도록 구현하였으며, 탐색 과정을 애니메이션 형태로 표현하여 알고리즘의 동작 과정을 쉽게 이해할 수 있도록 구성하였습니다.

---

## 🎯 프로젝트 목표

알고리즘을 단순히 구현하는 것에서 끝나는 것이 아니라, BFS의 탐색 원리와 최단 경로 탐색 과정을 시각적으로 표현하여 학습 및 이해를 돕는 데 목적을 두고 개발하였습니다.
