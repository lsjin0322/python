## 📖 프로젝트 소개

Dart를 활용하여 **우선순위 큐(Priority Queue)** 를 직접 구현한 자료구조 프로젝트입니다.

일반적인 큐(Queue)가 먼저 들어온 데이터를 먼저 처리하는 FIFO(First In First Out) 방식이라면, 우선순위 큐는 데이터마다 부여된 우선순위(Priority)를 기준으로 높은 우선순위를 가진 데이터를 먼저 처리합니다.

본 프로젝트에서는 가중치(우선순위)를 기준으로 데이터를 정렬하여 관리하는 우선순위 큐를 구현하였습니다.

## ✨ 주요 기능

* 우선순위 기반 데이터 관리
* 데이터 삽입(Enqueue)
* 데이터 추출(Dequeue)
* 최우선 데이터 조회(Peek)
* 큐 상태 확인(IsEmpty)
* 제네릭(Generic) 기반 다양한 데이터 타입 지원

---

## 🧠 구현 내용

각 데이터는 실제 값(Data)과 우선순위(Priority)를 함께 저장하는 `PriorityItem` 클래스로 관리하였습니다.

데이터가 삽입될 때마다 우선순위를 기준으로 정렬하여 항상 가장 높은 우선순위를 가진 데이터가 큐의 앞쪽에 위치하도록 구현하였습니다.

또한 제네릭(Generic)을 적용하여 문자열, 숫자, 객체 등 다양한 타입의 데이터를 저장할 수 있도록 설계하였습니다.

---

## 🔍 동작 방식

1. 데이터와 우선순위를 함께 입력
2. 우선순위를 기준으로 정렬
3. 가장 높은 우선순위의 데이터가 큐의 앞에 위치
4. Dequeue 수행 시 가장 높은 우선순위 데이터 반환
5. Peek 수행 시 삭제 없이 최우선 데이터 확인

---

## 🎯 프로젝트 목표

우선순위 큐 자료구조의 동작 원리를 이해하고, 일반 큐와의 차이점을 학습하는 것을 목표로 개발하였습니다.

또한 객체지향 프로그래밍(OOP)과 제네릭(Generic)을 활용하여 재사용 가능한 자료구조를 설계하는 경험을 쌓을 수 있었습니다.
